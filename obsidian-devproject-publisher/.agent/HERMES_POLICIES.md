# DevProject Publisher scope
Standalone Obsidian TypeScript plugin. Candidate-only development; installation, vault writes/reload, real uploads/publication, production requests, commit/push require separate approval. Never change other plugins.
Run npm run build and npm test against the CommonJS artifact. Tests deny live networking and use synthetic data only. Do not claim physical mobile or real Obsidian evidence from VM tests.
Credentials: fixed SecretStorage ID only; memory session, no plaintext fallback/logging. Export selected note only; no dependency note reads, remote images, automatic publication, arbitrary stylesheets or SVG.
Independent exact-hash review required before integration/install. Parent owns Project/EventNote/Resource/Dictionary documentation; LiveSync user-managed.
Hermes policy updates must update both common policy and this project-specific section.
